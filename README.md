# To-Do List App

## Objective
Create a simple task management application that helps users add, delete, and mark tasks as completed with persistent data storage.

## Features
- Add new tasks  
- Delete existing tasks  
- Mark tasks as completed  
- Data persistence using local storage  

## Technologies
- HTML  
- CSS  
- JavaScript  

## How to Use
1. Enter a task in the input field.  
2. Click the add button to save the task to the list.  
3. Click the delete button to remove a task.  
4. Click on a task to mark it as completed or uncompleted.  
5. Tasks are saved automatically and will persist after page reloads.  

## Installation
- Clone or download the repository.  
- Open `index.html` in a modern web browser.  
- Start managing tasks efficiently.
